# Python UV Workspace

## Description

This project was created as part of the Python, uv, VS Code and Jupyter Notebook TP.

The project uses `uv` to manage the Python environment and dependencies.

## Technologies

- Python
- uv
- VS Code
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

## Project Structure

- `app.py` : Python application used to test the installed libraries.
- `hello.ipynb` : Hello World Jupyter Notebook.
- `pyproject.toml` : Project configuration and dependencies.
- `uv.lock` : Locked dependency versions.
- `.python-version` : Python version used by the project.

## Execution

To run the application:

```bash
uv run app.py
